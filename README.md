# Personal Finance Manager

Sistema web para gerenciamento de finanças pessoais.

## 🚧 Status

Em desenvolvimento.

## 🛠️ Stack

- Laravel
- Vue 3
- TypeScript
- Inertia.js
- PostgreSQL
- Tailwind CSS
- Docker

## 🎯 Objetivo

O Personal Finance Manager será uma aplicação web destinada ao gerenciamento de finanças pessoais.

O sistema permitirá que usuários registrem suas contas financeiras, organizem receitas e despesas por categorias e acompanhem sua situação financeira por meio de um dashboard.

O objetivo inicial não é substituir aplicativos bancários ou sistemas financeiros completos, mas fornecer uma ferramenta simples para **registrar, organizar e visualizar informações financeiras pessoais**.

## ✨ Funcionalidades

- Autenticação
- Contas
- Categorias
- Transações
- Dashboard
