# Personal Finance Manager

Aplicação web Full Stack para gerenciamento de finanças pessoais, desenvolvida com Laravel, Vue 3, TypeScript, Inertia.js, PostgreSQL, Tailwind CSS e Docker.

O projeto foi desenvolvido com foco em organização de código, separação de responsabilidades, autenticação, autorização, modelagem de dados e implementação de regras de negócio.

## 🎯 Objetivo

O Personal Finance Manager tem como objetivo fornecer uma ferramenta simples para registrar, organizar e visualizar informações financeiras pessoais.

A aplicação permite que usuários gerenciem suas contas financeiras, organizem receitas e despesas por categorias e acompanhem sua situação financeira por meio de um dashboard.

O projeto não tem como objetivo substituir aplicativos bancários ou sistemas financeiros completos, mas oferecer uma solução para organização e acompanhamento das finanças pessoais.

## 🏗️ Arquitetura

O projeto utiliza uma estrutura organizada em camadas, buscando separar responsabilidades e facilitar a manutenção e evolução da aplicação.

Entre os principais componentes utilizados estão:

- Controllers — gerenciamento das requisições e respostas.
- Form Requests — validação e autorização das entradas.
- Services — organização da lógica de negócio.
- Models — representação e relacionamento dos dados.
- Policies — controle de autorização e acesso aos recursos.

## 🔐 Autenticação e autorização

A aplicação utiliza autenticação baseada no ecossistema Laravel.

As Policies são utilizadas para controlar o acesso aos recursos e garantir que usuários possam acessar e modificar apenas os dados aos quais possuem permissão.
